# OpenMP

## Задания
Михаил Курносов (https://www.mkurnosov.net/)

### Задание 1
Используя семинар 1 Михаила Курносова, реализовать
 __умножения матрицы на вектор с параллельной инициализацией массивов.__   
 Для элементов массива используйте тип double.
 Размеры матриц: 20000x20000, 40000x40000.

### Задание 2
Используя семинар 2 Михаила Курносова, реализовать
 __численное интегрирование, с использованием «#pragma omp atomic» и локальной переменной.__   
 nsteps = 40 000 000.

### Общие требования
- 1,2,4,7,8,16,20,40 потоков.

Описать вычислительный узел:
1. наименование и краткая характеристика CPU (lscpu),
2. наименование сервера (cat /sys/devices/virtual/dmi/id/product_name),
3. сколько NUMA node (numactl --hardware), сколько памяти у каждой ноды,
4. операционная система (cat /etc/os-release).

Построить график ускорения в зависимости от количества потоков:

Написать вывод о маштабируемости.
Результат сохранить в формате pdf, и прикрепить в гугл класс.  
<u>Дополнительно</u> (по желанию):  
Привязать потоки к ноде или конкретным ядрам,
и сравнить результат с предыдущим (без привязки).

### Задание 3
Выполнить «Лабораторную работу No2»,   
  используя метод простой итерации.

#### 
**Исходные данные**  
  Элементы главной диагонали матрицы A равны 2.0, остальные равны 1.0.
  Все элементы вектора b равны N+1. В этом случае решением системы будет
  вектор, элементы которого равны 1.0. Начальные значения элементов
  вектора x можно взять равными 0.
