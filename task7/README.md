## cuBLAS theory (`bespolezno`)

#### Подключение и вызов cuBLAS
Изначально BLAS был разработан  для Fortran.   
Поэтому приходиться использовать вправляющий макрос
```c
// Макрос индексации, индексация начинается с единицы
#define IDX2F(i, j, ld) ((((j)-1) * (ld))+((i)-1))
// Макрос индексации, индексация начинается с нуля
#define IDX2C(i, j, ld) (((j) (ld))+(i))
```

```c
//Подключаем библиотеку
#include <cublas_v2.h>
//Макрос индексации
#define IDX2F(i,j,ld) ((((j)-1)*(ld))+((i)-1))

int main(void) {
    //создаем указатель на структуру, содержащую контекст
    cublasHandle_t handle;
    
    // инициализация контекста
    cublasCreate(&handle);
    
    /****
    *
    Вызов функций библиотеки cuBlas, на данном устройстве
    * ****/
    
    // удаления контекста, освобождаем ресурсы
    cublasDestroy (handle);
}
```

#### Типы данных
| Тип данных `<type>` | Символ `<t>` | Описание (Meaning) |
| :--- | :--- | :--- |
| `float` | 's' or 'S' | 	Вещественное число одинарной точности |
| `double` | 'd' or 'D' | 	Вещественное число двойной точности |
| `cuComplex` | 'c' or 'C' | Комплексное число одинарной точности |
| `cuDoubleComplex` | 'z' or 'Z' | Комплексное число двойной точности |

#### Компиляция
В pgcc/pgc++ используем опцию `-cudalib=cublas`.
