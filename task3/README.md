## Задание 2: клиент-серверное приложение
#### Сервер
Сервер представляет из себя отдельный поток, который берет задачи из
очереди, решает их и сохраняет результат в контейнер (подберите оптимальный
контейнер, в который можно быстро добавлять и удалять элементы, а также
искать их). Реализовать в виде шаблона класса.
У сервера обязательно должны быть следующие функции-члены (интерфейс):
1. void start() - запустить сервер;
2. void stop() - остановить сервер;
3. size_t add_task(task) - добавить задачу, тип task в параметрах функции
на ваше усмотрения. Возвращает id задачи;
4. T request_result(id_res) - возвращает результат типа T. Может быть
блокирующим или не блокирующим.

#### Клиенты
Клиенты представляют из себя отдельные потоки, которые добаляют
задачи в очередь, дожидаются результата и сохраняют в файл. Создать три
клиента, каждый добавляет по N (5<N<10000) задач. Для каждого клиента
использовать следующие задачи (каждый клиент добавляет только один тип
задач):
1. вычисление синуса, аргумент задавать рандомно;
(`std:sin(arg)`)
2. вычисление квадратного корня, аргумент задавать рандомно;
(`std:sqrt(arg)`)
3. возведение числа в степень, аргументы задавать рандомно.
(`std:pow(x, y)`)

#### Результат
Результаты в файлах должены быть удобны для чтения и проверки.
* Написать тест, который читает результаты предыдущей программы из файлов и
проверяет.

* Осторожно: При работе с общими ресурсами (очередь, контейнер, переменные) из
разных потоков, не забывайте синхронизировать доступ к ним. Метод get() у
future можно вызывать только один раз.
